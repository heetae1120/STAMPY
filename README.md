# 스탬피

식당, 카페, 제품 체험단 플랫폼 스탬피의 웹사이트입니다.

**사이트 주소:** [https://heetae1120.github.io/STAMPY/](https://heetae1120.github.io/STAMPY/)

- `index.html`: 업체소개 메인페이지. 음식·제품 사진을 넣은 Originkit Hero 03 원근 배경과 캠페인 유형 안내.
- `campaigns.html`: 리뷰어 캠페인 페이지.
- `styles.css`: 업체소개 페이지 스타일. 리뷰어 스타일은 해당 HTML 안에 있습니다.

## 개발과 빌드

Node.js 24와 npm 기준:

```sh
npm ci
npm run typecheck
npm run build
python -m http.server 8000 --bind 127.0.0.1
```

`npm run build`는 `src/hero-03.tsx` 및 Originkit에서 가져온 터널 렌더러를 `assets/hero-03/hero.js`로 묶습니다. 빌드 결과도 Git에 포함하므로 GitHub Pages는 루트 정적 파일을 그대로 배포합니다. 런타임 서버나 Originkit API 키가 필요하지 않습니다.

Hero 03의 3D 터널/반응형 크기 소스는 `components/originkit/ui/hero-03`에 있습니다. 정적 HTML 사이트에 맞게 메인 페이지에는 움직이는 3D 사진 배경을 표시하고, 캠페인 버튼은 캠페인 목록으로 이동합니다. 별도의 Tailwind/Next.js 앱을 도입하지 않았습니다. 상세한 가져오기·변경·검증 기록은 `HERO_03_INTEGRATION.md`를 참고하세요.

수정 후 `npm run build`를 실행하고 소스와 빌드 결과를 함께 커밋하세요. 지도 표시용 공개 Key ID는 설정 파일에 포함되며 Client Secret은 저장소에 넣지 않습니다.

`[가격]`, `[회사명]` 등은 운영자가 채울 자리입니다. 캠페인은 예시 데이터이며 신청·프로필은 브라우저 localStorage에만 저장됩니다. 캠페인 지도는 네이버 지도를 사용하며 매장 핀은 실제 주소가 아닌 예시 위치입니다.

## 네이버 지도 활용 계획

현재 캠페인 페이지의 **지도로 보기**에서 방문형 캠페인과 예시 위치를 표시하며, 지도에서 매장을 선택해 상세 화면을 열 수 있습니다. 아래 항목은 향후 검토할 기능입니다.

### 리뷰어용

- **내 주변 체험단**: 위치 제공에 동의한 사용자의 주변 캠페인을 표시하고 거리순으로 정렬합니다.
- **지도와 목록 연동**: 현재 보이는 지도 영역의 캠페인만 목록에 표시하고, 목록 선택 시 해당 핀으로 이동합니다.
- **캠페인별 핀과 정보창**: 업종별 아이콘·색상과 제공 내용·모집 마감일을 표시합니다.
- **캠페인 상세 지도**: 해당 매장을 확대해 위치를 확인할 수 있게 합니다.
- **거리뷰·항공뷰**: 지원되는 지역에서 매장 주변을 살펴볼 수 있게 합니다.

### 운영자용

- **주소로 위치 등록**: 입력한 주소를 좌표로 변환해 매장 핀을 표시합니다.
- **핀 위치 조정**: 지도에서 핀을 옮겨 매장 입구 등의 위치를 수정합니다.
- **지역별 현황**: 등록된 캠페인의 지역별 분포를 지도에 표시합니다.

우선순위는 주소 기반 실제 매장 위치 등록, 캠페인 상세 지도, 내 주변 검색 순으로 검토합니다. 주소 변환은 별도 Geocoding 연동 및 설정 확인이 필요합니다. 실제 캠페인과 주소를 여러 사용자에게 제공하려면 백엔드와 데이터베이스가 필요하며, 위치 정보 사용 시 이용자 동의를 받아야 합니다. 제공 범위·이용 조건·요금은 구현 시 확인합니다.

참고: [네이버 지도 API 예제](https://navermaps.github.io/maps.js.ncp/docs/tutorial-digest.example.html), [네이버 지도 API 문서](https://navermaps.github.io/maps.js.ncp/docs/).
