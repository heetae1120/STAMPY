# Stampy demo collection

12 original SVG campaign illustrations and six matching store monograms created for this project. The collection uses fictional brands and is not evidence of a commercial partnership or an active recruitment campaign. No third-party product photography or externally hosted images are used.

- c1: OVEN & TABLE / pizza
- c2: ROOF & CRUMB / dessert
- c3: GRAIN DAY / granola
- c4: MOOD NAIL / nail polish
- c5: SOFT SUNDAY / fabric care
- c6: DESK JOURNAL / desk editorial
- c7: STAY SLOW / seaside accommodation
- c8: 골목의 식탁 / soup
- c9: BARE LEAF / sunscreen
- c10: ROOM NOTE / home editorial
- c11: SLOW POUR / coffee
- c12: FORM / DESK / laptop stand

Campaign IDs, channels, quotas, filtering and browser-only applications are retained. The carousel has three collections: regional autumn experiences, home products, and a reviewer guide. Its actions use existing filters or the guide dialog. Autoplay pauses on focus, hover, hidden document and reduced-motion preference; navigation and pause controls remain available.
